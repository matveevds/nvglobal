### R-15. Переписывание секции роняет чужие правила — ПРОЦЕСС ИСПРАВЛЕН
При переписывании секции целиком (`/* X START */ … /* X END */`) внутри блока
оказывались правила **других** компонентов, и они уходили вместе с секцией.

Найдено и восстановлено за группы 1–4:

| Где лежало | Что потерялось | Кого ломало |
|---|---|---|
| `DOC` | `@media 767.98 { .btn--black span { font-size: 16px } }` и ещё 14 правил | `/solutions/` (+2px в `section.cta`) |
| `CLIENTS` | `.company__item` | блок компаний |
| `ABOUT` | `@media 1199.98 { .teaser__maskot.teaser__maskot--about }` | `main-page-video-autoplay.php` |
| базовый блок кнопок | `.btn-hero` (база), `.btn__text-hero`, три правила `:hover`/`.is-active` | `/pricing-matrix/`, `/404/`, `/blog/`, архивы |

Последний случай — самый тяжёлый: группа 1 переписала `.btn-hero` **глобально**,
и на страницах вне главной кнопка теряла фон (`var(--nv-gradient)` объявлена
только в `body.home`, вне её свойство невалидно → прозрачный фон), высота
64 → 40, радиус 16 → 8, текст оставался без цвета.

**Правило на будущее:** перед переписыванием секции прогонять по её старому
телу разбор CSS, который заходит **внутрь `@media`**, и сверять каждый селектор
с префиксом секции. Обычный просмотр правил верхнего уровня этого не ловит.
Все новые глобальные селекторы ограничивать `body.home`.

Скрипты проверки: `lost2.py` (потерянные чужие селекторы),
`unscoped.py` (новые глобальные), `mod.py` (изменённые правила общих классов),
`snap.mjs` (поэлементное сравнение страниц с эталоном до редизайна).

`css/styles.css:12822` → `.packages__service-icon { background-image: url('../img/info.svg') }`.

### B-02. GLightbox не подключён — лайтбокс не работает
Файлы лежат в `assets/glightbox/`, но `wp_enqueue_script` для них нет нигде
(enqueue есть только в соседней теме `wp-content/themes/neurovision`).
Проверено в браузере: `window.GLightbox === undefined`.
`js/main.js:804` делает `if (typeof GLightbox === 'undefined') return;` — `initLightboxAndForms()`
молча выходит, ошибок в консоли нет.
**Решено (Р-3): не восстанавливать.** Проверка показала, что функциональность
не используется нигде: `class="glightbox"` в шаблонах и блоках — 0 вхождений;
в живом DOM шести страниц `.glightbox` / `[data-glightbox]` / `[data-gallery]` — по нулю;
блоки с изображениями триггеров не выдают.
Понадобится при редизайне — подключать **локальную** `assets/glightbox/`, не CDN.

**Уточнение:** формы не страдают. `initLightboxAndForms()` вызывает `initPhoneFields`,
`initHelpSelect` и `initContactsForms` **до** проверки на `GLightbox`.

### B-03. ACF-группа «Главная страница» ни на что не влияет

## P3 — расхождения с регламентом

> постепенно, по ходу редизайна каждой секции.

### B-13. Табы без ARIA
Полный набор ролей есть **только** у `blocks/tabs/tabs.php`.
Собственные табы темы — `initDocTabs` (главная), `initFeaturesBlock` и `initBenefitsSlider`
(`/solutions/`) — работают без `role="tablist"` / `role="tab"` / `role="tabpanel"`,
без `aria-selected`, `aria-controls`, roving tabindex и клавиатурной навигации.
Требование регламента: `docs/FRONTEND.md`, раздел 10.
**Новые компоненты делать правильно сразу**, старые дооснащать точечно.

### B-14. `@media (hover: hover) and (pointer: fine)`
Два правила в `styles.css`. Регламент требует ключом **только наличие hover**:
`pointer: fine` отсекает сенсорные и гибридные десктопы.
**Проверить, что именно сломается**, прежде чем снимать условие.

### B-15. `.btn-hero { height: 64px }`
`styles.css:1100`. Текстовая кнопка с фиксированной высотой — при переносе текста
или другом языке содержимое вылезет. Нужно `min-height` + `padding` + `box-sizing: border-box`.
В теме уже 40 `min-height`, приём знаком.

### B-16. Grid там, где регламент требует Flex
~8 мест: `video-intro` (2225), `solutions` (2434), `cases` (4493), hero (1440) и др.
Соотношение по файлу — 396 `display:flex` против 47 grid-объявлений.
Миграция — рефакторинг, не побочный эффект правки. **Новый код пишем на Flexbox.**

### B-17. Схема x1/x2 WebP не применяется
В `img/` ровно **один** файл `@2x`, `srcset` встречается в 3 шаблонах.
65 PNG и 17 JPG не переведены в WebP. Регламент требует `name.webp` + `name@2x.webp`
с явными `width`/`height`. Применять **к новым ассетам**; массовый перевод старых — отдельная задача.

6 меню `nav_menu` в парах RU/EN, `theme_mods_nvglobal` ссылается на локацию `main_menu`,
которую тема не регистрирует. Навигация в `header.php` захардкожена.
**Не удалять** — пригодятся, если навигацию переведут на `wp_nav_menu()`.

### B-25. Дефекты маркеров секций в `styles.css`
- Строки 1–649 и 930–1501 не накрыты маркерами.
- `MENU … START` (650) закрывается `HEADER MENU … END` (930) — имена не совпадают.
- `HERO END` (1501) есть, `HERO START` — нет.
- После `CALC PAGE END` (13435) висит бесхозное правило чат-виджета.

Чисто косметика комментариев, на рендер не влияет, но ломает навигацию по файлу.
